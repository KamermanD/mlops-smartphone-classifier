# Smartphone Classifier

## Описание проекта

Проект представляет собой систему классификации брэндов моделей смартфонов по изображениям.
Основная цель — научить модель различать брэнды моделей телефонов по их изображению.

### Основные этапы работы проекта

1. **Загрузка данных**
   Данные хранятся через DVC, что позволяет легко синхронизировать их с удалённым хранилищем (Google Drive, S3 или локальный диск).

2. **Препроцессинг**
   Применяются стандартные трансформации изображений:
   - изменение размера до 224x224
   - нормализация
   - аугментации (только для обучающего датасета, например, случайный горизонтальный переворот)

3. **Модель**
   Используется Vision Transformer (`vit_b_16`) с модифицированным классификационным слоем под количество классов.
   Также есть baseline resnet+svm. Все jupyter ноутбуки лежат в папке notebooks, можете ознакомиться. Результирующая accuracy должно получится 0.96,
   если использовать такие же гиперпараметры, как в ноутбуке. Параметры можно вводить в папке config файл train.yaml. По умолчанию я поставил по 3 эпохи и 8 бачей,
   так как у меня слабенький компьютер, а модель обучал на colab. Там же через переменную num_samples можно ограничивать количеству картинок, если нужно просто проверить обучение и не особо долго ждать, потому что в моё датасете 7000 картинок, обучать придется 2 часа на мощьном компьютере. Через data.yaml можно установить  test_size и random_seed.

4. **Обучение**
   Обучение происходит поэтапно с возможностью замораживания слоев модели и поэтапной настройкой learning rate и веса регуляризации. Т.е. модель мы поэтопно размораживаем, начиная с верхнего слоя и обучаем постепенно спускаясь вниз по слоям. Количество stage - количество слоев, которые мы разморозим для дообучения. Это называется finetuning.

5. **Логирование**
   Используется MLflow для отслеживания метрик, параметров и сохранения моделей. Также строятся графики loss и accuracy на протяжении обучения.

## Setup

Для запуска проекта необходимо настроить окружение и зависимости. Я использую **Poetry**.

1. Клонируем репозиторий:

   git clone https://github.com/KamermanD/mlops-smartphone-classifier.git

2. Создаём виртуальное окружение py (у меня Windows, поэтому для Windows использовал такие команды) :

   py -m venv venv (у меня версия Python 3.11.0, если что)

   .\venv\Scripts\Activate.ps1

3. Устанавливаем poetry: (если не глобально)

   pip install poetry

   python -m pip install --upgrade pip (ели это необходимо, у меня без этого в poetry install были ошибки)

4. Запуск установки зависимостей:

   poetry install



5. Подгружаем данные через DVC:

   dvc pull  # remote "myremote" уже прописан в .dvc/config

6. Для запуска обучения можно использовать одну из двух команд:

   1. Через Python:

      poetry run python commands.py

   2. Через DVC:

      dvc repro

7. Установка pre-commit:

   pip install pre-commit

   pre-commit run -a

Описание файлов:

data.yaml — настройки загрузки и разбиения данных

model.yaml — гиперпараметры модели

train.yaml — параметры обучения

mlflow.yaml — параметры логирования

Результаты обучения:

Лучшая модель сохраняется в outputs/models/best.pth .
Графики обучения (loss, accuracy) сохраняются в outputs/models/logs/ .
Параметры и метрики сохраняются в MLflow.
